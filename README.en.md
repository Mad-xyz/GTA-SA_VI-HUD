# GTA SA VI HUD

[Leia esta página em português do Brasil](README.md)

A HUD mod for **classic Grand Theft Auto: San Andreas**, inspired by the visual style of **GTA VI HUD: Legacy and Enhanced Support**, originally made for GTA V.

The project aims to adapt elements of that HUD style for GTA San Andreas. It is still under development.

## Current status

- **Version:** v0.584
- **Status:** experimental build
- **Development:** in progress

This is an early port. Bugs, visual issues, and features that do not work as expected may still be present. I am working on fixes and adjustments. Behavior may vary depending on the game setup, and full compatibility has not yet been confirmed.

Back up your game files before testing any mod. Use this build at your own risk, and include screenshots or logs when reporting problems.

## Included files

- `MHud.asi`: compiled HUD plugin.
- `MHudAudio/`: audio files used by the mod.
- `VIHud-SA-Map-Port-Assets/`: PNG visual assets used by the port.
- `VIHudVehicleCard.ini`: vehicle card configuration file.
- `vihud_wheel_icons.txd`: weapon wheel icon texture.

**Note:** this release contains the compiled plugin and supporting files. The plugin's source code is not included in this repository version. Installation instructions and requirements may change while development continues.

## Bug reports

When reporting a problem, include your GTA San Andreas version, the mod loaders you have installed, what you did before the issue occurred, and a screenshot or log if possible. This information helps reproduce the issue.
