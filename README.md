# GTA SA VI HUD

[Read this page in English](README.en.md)

Um mod de HUD para **Grand Theft Auto: San Andreas clássico**, inspirado no visual do projeto **GTA VI HUD: Legacy and Enhanced Support**, originalmente feito para GTA V.

O objetivo é adaptar elementos desse estilo de HUD ao GTA San Andreas. O projeto ainda está em desenvolvimento.

## Estado atual

- **Versão:** v0.584
- **Status:** build experimental
- **Desenvolvimento:** em andamento

Esta é uma versão inicial do port. Ainda existem bugs, falhas visuais e recursos que podem não funcionar como esperado. Estou trabalhando nos ajustes e nas correções. O comportamento pode variar conforme a instalação e a configuração do jogo, e a compatibilidade completa ainda não está garantida.

Faça backup dos arquivos do jogo antes de testar qualquer mod. Use esta versão por sua conta e salve capturas de tela ou logs ao relatar problemas.

## Arquivos incluídos

- `MHud.asi`: plugin compilado do HUD.
- `MHudAudio/`: arquivos de áudio usados pelo mod.
- `VIHud-SA-Map-Port-Assets/`: recursos visuais em PNG usados no port.
- `VIHudVehicleCard.ini`: arquivo de configuração do cartão de veículo.
- `vihud_wheel_icons.txd`: textura de ícones da roda de armas.

**Nota:** esta publicação contém o plugin compilado e os arquivos auxiliares. O código-fonte do plugin não está incluído nesta versão do repositório. As instruções e os requisitos de instalação poderão mudar enquanto o projeto estiver sendo desenvolvido.

## Relatar um bug

Ao relatar um problema, informe a versão do GTA San Andreas usada, os carregadores de mods instalados, o que você fez antes de o erro acontecer e, quando possível, inclua uma captura de tela ou log. Isso ajuda a reproduzir o problema.
